Вход через GitHub

Как получить токен?
1. github.com → ваш аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Repository access: «Only select repositories», отметьте хранилища с музыкой.
3. Repository permissions → Contents: Read and write.
4. Скопируйте токен (начинается с github_pat_) сюда. Логин и пароль GitHub для такого входа не работают, GitHub их больше не принимает.
5. Пароль выше придумайте сами: токен хранится на устройстве только в зашифрованном виде, при входе вводите этот пароль.
6. Каждое хранилище должно быть создано с любым файлом (например README), пустое не подойдёт.

2. Загрузка треков

Перетащите сюда файлы или папку mp3, flac, wav, m4a, ogg и обложки jpg/png/webp. Без ограничения по количеству; один файл — до 95 МБ.
Называйте файлы так: Артист - Название.mp3. Жанр — это подпапка внутри music. Одинаковые песни, которые уже есть на сайте, отмечаются и по умолчанию не загружаются.
