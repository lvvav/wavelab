Первая настройка

Где взять токен?
1. Откройте github.com/settings/personal-access-tokens/new
2. Name: любое, Expiration: например 1 год
3. Repository access → Only select repositories → ваш репозиторий сайта
4. Permissions → Repository permissions → Contents: Read and write
5. Generate token и скопируйте github_pat_…
Дополнительно
Токен шифруется вашим паролем и хранится только на этом устройстве. Дальше для входа нужен будет только пароль.

2. Загрузка треков

Перетащите сюда файлы или папку mp3, flac, wav, m4a, ogg и обложки jpg/png/webp. Без ограничения по количеству; один файл — до 99 МБ.
Называйте файлы так: Артист - Название.mp3. Жанр — это подпапка внутри music. Одинаковые песни, которые уже есть на сайте, отмечаются и по умолчанию не загружаются.
